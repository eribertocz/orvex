# 0017 — Semantic Versioning; the MVP is v1.0.0 stable

**Status:** Accepted (2026-10-26)

## Context
The manager and department heads will make decisions with Sextant's numbers. The Owner prioritizes quality over speed.

## Decision
- Semantic Versioning 2.0.0; module versions and product versions (`process/versioning.md`).
- Each roadmap phase ends with an alpha pre-release; when the full MVP scope is implemented, betas with pilot users; then release candidates; **the MVP is released as v1.0.0 stable** when the release criteria are met.
- Alpha/beta describe contract stability, never correctness or security.

## Alternatives considered
- Shipping the MVP as alpha: incompatible with real decision-making use.

## Consequences
The roadmap defines exit criteria and versions per phase (`roadmap.md`).
